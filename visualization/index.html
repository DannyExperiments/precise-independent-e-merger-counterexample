Why these four inputs suffice

At Bi just the i-th input equals zero and the merger copies it. A strategy that first reads i with zero first wager retains its initial capital. The remaining inputs 1/4 and 3/4 are positive, so the terminal wealth stays positive.

For any mixture M, the four evaluations obey M(A) ≤ 1/4 + 4(M(B1) + M(B2) + M(B3)). The displayed target has values 1, 0, 0, 0. Its maximum error from any mixture on this set is at least 3/52.
